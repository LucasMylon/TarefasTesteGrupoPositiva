🎓 COMO USAR
─────────────────────────────────────────────────────────────

1. Obter token da API de Usuários:
   POST /api/usuarios/login
   Resposta: { "accessToken": "eyJhb..." }

2. Usar token nos endpoints:
   GET /api/tarefa
   Header: Authorization: Bearer eyJhb...

3. Resposta:
   - 200: Array com tarefas do usuário
   - 401: Token inválido ou expirado
   - 403: Sem permissão

⚠️ PROBLEMAS?
─────────────────────────────────────────────────────────────

AppLocker bloqueia DLLs?
  → Use Release mode: dotnet run -c Release
  → Ou leia: APPLOCK_SOLUTION.md

Chave JWT inválida?
  → Deve estar em Base64
  → Exemplo: AQIDBAUGBwgJCgsMDQ4PEBESExQVFhcYGRobHB0eHyA=

Banco de dados?
  → Funciona com banco existente
  → Sem migração necessária
