   │ POST /api/tarefa                                    │

   │ Resposta: 201 Created                               │

   ┌─────────────────────────────────────────────────────┐
   │ PUT /api/tarefa/{id}                                │
   │ Atualizar tarefa                                    │

   │ Resposta: 200 OK                                    │
   └─────────────────────────────────────────────────────┘

   ┌─────────────────────────────────────────────────────┐
   │ DELETE /api/tarefa/{id}                             │
   │ Excluir tarefa (apenas se não concluída)           │
   │ Resposta: 204 No Content                            │
   └─────────────────────────────────────────────────────┘

   1. OBTER TOKEN
	  ┌────────────────────────────────────────────┐
	  │ POST /api/usuarios/login                   │
	  │ Body: { email, senha }                     │
	  │ Resposta: { accessToken: "eyJ..." }        │
	  └────────────────────────────────────────────┘

   2. USAR TOKEN
	  ┌────────────────────────────────────────────┐
	  │ Authorization: Bearer eyJ...               │
	  └────────────────────────────────────────────┘

   3. VALIDAÇÃO AUTOMÁTICA
	  ┌────────────────────────────────────────────┐
	  │ Middleware valida:                         │
	  │ • Assinatura (HMAC-SHA256)                 │
	  │ • Issuer = "Usuarios.App.API"              │
	  │ • Audience = "Usuarios.App.Clients"        │
	  │ • Não expirado                             │
	  └────────────────────────────────────────────┘

   4. ISOLAMENTO
	  ┌────────────────────────────────────────────┐
	  │ Email extraído do token                    │
	  │ ↓                                          │
	  │ Tarefas filtradas: WHERE email == email   │
	  │ ↓                                          │
	  │ Resposta: Apenas tarefas do usuário        │
	  └────────────────────────────────────────────┘

   COMO CONFIGURAR:
   PowerShell:
   ┌────────────────────────────────────────────┐
   │ $secretKey = [Convert]::ToBase64String(   │
   │   [byte[]]@(1..32)                         │
   │ )                                          │
   │ $env:JWT_SECRET_KEY = $secretKey           │
   └────────────────────────────────────────────┘

   COMO INICIAR:
   PowerShell/Bash:
   ┌────────────────────────────────────────────┐
   │ cd TarefasTeste                            │
   │ dotnet run --project TarefasTeste.Api \\  │
   │   --configuration Release                 │
   └────────────────────────────────────────────┘
